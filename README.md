## How to import

1. Open n8n (n8n.cloud or self-hosted) → **Workflows → Add workflow**.
2. **⋯** menu (top right) → **Import from File** → pick a `.json` file.
3. Read the yellow sticky note on the canvas and follow its setup steps.
4. Add your own credentials: **Anthropic (Claude)**, and as needed **Google Sheets**, **Gmail**, **WhatsApp Business Cloud**, **Telegram**, **Google Calendar / Docs / Drive**. These files contain no keys or IDs.
5. Replace every `YOUR_...` placeholder (sheet link, WhatsApp Phone Number ID, your number, email, etc.).
6. Click **Execute workflow** once with test data and your own number, check the result, then switch it to **Active**.

## Tips

- Start with one agent. Easiest first: **28 Daily Cash Report** or **22 Bill Reader** (Sheets/Gmail + Claude).
- Use **one Google Sheet** for all agents, one tab per list (Leads, Orders, Sales, Expenses, Tickets, Tasks, Stock...). The CEO agent and 49 Weekly Summary read those same tabs.
- Phone numbers go in 91XXXXXXXXXX format (country code, no + or spaces).
- WhatsApp Cloud API allows **one webhook per Meta app**. If you run several WhatsApp-trigger agents (02, 11, 33, 34, 50...), use one WhatsApp trigger workflow that routes messages to the others, or a separate Meta app/number per agent.
- WhatsApp only lets you send free-form messages within 24 hours of the customer's last message. For cold or scheduled messages (reminders, broadcasts) use an approved **template**.
- Point anything that sends messages at your own number or a draft until you trust it. Angry customers, refunds and discounts always come to you; the AI never promises them.
- Model: Claude nodes use `claude-sonnet-5-5`; switch in the model node if you like (OpenAI / Gemini work too).
